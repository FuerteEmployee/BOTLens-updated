Camera Troubleshooting

  • 🔒 Check HTTPS: Ensure your URL starts with https://.
  • ✅ Permissions: Click the lock/camera icon in the address bar and Allow Camera.
  • 🔌 Check Device: Ensure your camera is not being used by another app (Zoom, Meet).
  • 🛠️ Advanced (Local IP): If using an IP address (e.g. 192.168.x.x), go to:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
    and add https://YOUR_IP:8000 to the list.
